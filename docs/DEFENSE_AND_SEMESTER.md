# Підготовка до захисту та матеріали семестру

Після завершення погодженого плану програма додає окреме завдання підготовки до захисту. Для попередньо завершених робіт відкрийте «Файли» → «Підготовка до захисту». Автоматичний запуск можна вимкнути в налаштуваннях. Помилки підготовки не скасовують уже виконані обчислення й не запускають навчання повторно.

Посібник містить пояснення теми з основ, словник, формули й методи, вхідні дані, кожен етап, розбір коду за файлами та рядками, результати, перевірки й обмеження, 15 запитань із відповідями, усний виступ і самоперевірку. Для робіт без коду відповідних розділів немає. Розмір визначається змістом; одна фіксована кількість сторінок не гарантує повноти.

Створюються окремі defense.md та defense.docx; defense.pdf — за доступності LibreOffice. Звіт лабораторної не перезаписується. Файли мають позначку «Потребує перегляду»: оцінка LLM не гарантує правильність. При помилці перевірки відхилений текст не публікується як готовий посібник. Прийняті розділи зберігаються між повторними спробами, повторна кнопка для незміненої роботи повертає збережені файли.

Джерела — погоджена умова й фактичні результати, файли зі знімків запуску та теорія того самого предмета. Для Python беруться основний файл, перелічені виконані checker-файли та їх локальні імпорти; випадкові старі checker-файли не вважаються виконаними. Наявність функції з assert сама по собі не доводить, що її викликали. Нові лекції предмета можна використовувати для підготовки до захисту без зміни погодженої умови лабораторної. Зміни джерел змінюють відбиток посібника; повторна генерація створює нову версію. Для текстового хмарного адаптера зображення не вважаються переглянутими: пояснюються лише відомі з коду та даних параметри.

Хмара використовує чинний режим дозволу та загальний бюджет. У бюджетному режимі для довгих пояснень і перевірки змісту використовується погоджений провайдер. У разовому режимі автоматичного переходу в хмару немає. Кожне звернення враховується; це окреме навчальне завдання після лабораторної, яке може тривати довго.

## Додавання матеріалів

Початкова папка: D:\StudyAssistant\materials\semester. Для нових файлів використовуйте папки предметів і вкладені 01_Лекції, 02_Лабораторні, 03_Зразки_звітів, 04_Дані. Новий предмет можна додати власною папкою з його назвою. Для чинних п’яти предметів короткі назви в бібліотеці збережено, щоб не втратити зв’язок з існуючими роботами.

00_UNSORTED призначена для приймання несортованих матеріалів. Їх можна рознести по папках або явно класифікувати у _catalog.json: ключ — відносний шлях з прямими слешами, значення — subject та role (theory/task/reference/data/result). Каталог — лише метадані бібліотеки, він не надає документам права запускати команди. Оригінальні файли не змінюються. Бібліотека організована за предметом і призначенням, незалежно від того, де лежав оригінал.

На екрані «Бібліотека» перевірте розподіл, тоді натисніть «Імпортувати семестр». Читання виконується локально, підтримуються OCR і старі офісні формати за наявності залежностей. Однаковий SHA256 у тому самому предметі та ролі не імпортується двічі. Непідтримувані файли й помилки показуються окремо; OCR числа й формули потребують перевірки. Після читання в чергу додається локальна індексація embedding-моделлю. До її завершення доступний пошук за словами. Нові матеріали не виконують лабораторні й не змінюють погоджені плани самі собою.

Початковий ліміт — 500 файлів на один каталог семестру. Доданий користувачем набір 20 жовтня містить 129 файлів із чотирьох дисциплін; нові матеріали ЛМВ користувач вирішив поки не додавати.
