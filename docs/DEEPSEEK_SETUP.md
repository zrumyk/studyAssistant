# Підключення DeepSeek

Ключ зберігається у `D:\StudyAssistant\.env` під назвою `DEEPSEEK_API_KEY`. Значення після `=` читається без перезапуску. Не надсилай ключ у чат. `.env` виключено з Git, вихідного ZIP і резервних копій; `.env.example` містить лише порожній приклад.

Ключ уже перевірений реальними викликами. Провайдер — DeepSeek API, модель — `deepseek-flash`, режим thinking вимкнений для економії. Незавершені відповіді не виконуються й не повторюються автоматично. Вартість використаних токенів враховується навіть при обрізаній відповіді.

За останнім прямим дозволом користувача ввімкнено режим погодженого бюджету: до $0,03 на одне звернення і $5 на календарний місяць за київським часом. Запити в цих межах не потребують окремого підтвердження. У налаштуваннях можна повернути режим разового дозволу. Додавання ключа саме по собі не вмикає бюджетний режим.

Оцінка перед відправленням резервує консервативну верхню межу. Облік DeepSeek використовує пікові тарифи без знижок кешу; рахунок провайдера може бути нижчим. Ліміт програми охоплює лише її власні звернення. Текст, мета, модель, відповідь, використання токенів і стан завершення зберігаються у локальній історії.

На 20.10.2026 виконано три реальні звернення; консервативний облік — $0,0266244. Перше витратило ліміт на reasoning; друге дало повний код MNIST, який виправлено локально й перевірено запуском; третє перевищило довжину відповіді для Chest X-Ray. Для третього підготовлено окрему локальну реалізацію з позначенням авторства; незавершена хмарна відповідь не підміняється готовим результатом.
